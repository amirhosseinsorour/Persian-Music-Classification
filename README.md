# Instrument and Dastgah Recognition in Persian Traditional Music

**BSc Thesis · Amirkabir University of Technology · 2023**

This project investigates the automatic recognition of musical
instruments and Dastgahs in Persian traditional music using
audio processing and deep learning.

## Objectives

- Identify the instrument played in an audio recording.
- Identify the Dastgah associated with the recording.
- Investigate a multi-task model for both recognition tasks.

## Project scope

The thesis uses the Nava dataset, covering five instruments
and seven Dastgahs.

The approach combines audio features, including MFCCs and
Mel spectrograms, with convolutional and recurrent neural networks.
